# Security Policy

## Supported Versions

Axion Notes is pre-1.0 software. Security fixes are made for the latest released version only. Please update to the newest available release before reporting an issue.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Earlier releases | No |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, pull requests, or social media.

Report them privately by email to [solisware@mail.com](mailto:solisware@mail.com) with the subject line `Axion Notes security report`.

Include, where possible:

- A clear description of the issue and its potential impact
- Steps, proof of concept, or code needed to reproduce it
- The Axion Notes version, operating system, and installation method
- Any relevant logs or screenshots, with private note content and passwords removed

We will review the report, confirm the scope, and coordinate a fix and disclosure with you. Please allow reasonable time for a fix before making the vulnerability public.

## Security Scope

Reports are particularly welcome for issues involving:

- Local note encryption, decryption, and data integrity
- Lock screen and password protection
- Unauthorized access to notes or application settings
- Electron window, IPC, navigation, permission, or update security
- Exposure of note content through files, logs, screen capture, or other local data
